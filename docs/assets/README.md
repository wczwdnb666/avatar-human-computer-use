## 为什么不先放一张静态截图

静态截图证明不了**它真的在动** —— 而本项目的卖点恰恰是动作本身：

- 真人化轨迹（速度曲线 + 震颤 + 子运动分解）
- 检出风险就停下等人（熔断 + F9 恢复）
- 一个字一个字地打字，不是瞬间粘贴

这些**只有动图能表达**。放一张"记事本里有个 hello"的截图，
读者既看不出真人化，也看不出熔断。
