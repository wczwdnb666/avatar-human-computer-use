# 案例 4 · 真人化对比

**演示什么**：机械移动 vs 真人化移动的差别，以及"可复现"这件事。

## 跑

```bash
python -m avatar entropy --demo
```

**预期**：打印真人化轨迹的指标（速度曲线、震颤幅度、子运动分解），
并和机械直线对比。

```bash
# 可复现性：同一个 seed 跑两次，轨迹必须逐点相同
python -m avatar entropy --seed 42 --json > a.json
python -m avatar entropy --seed 42 --json > b.json
fc a.json b.json        # 应该完全一致
```

## 三个关键指标

| 指标 | 机械 | 真人化 | 为什么重要 |
|---|---|---|---|
| 速度曲线 | 匀速 | 先加速后减速（非对称） | 人类运动学的基本特征 |
| 轨迹 | 直线 | 微弯 + 8-12Hz 震颤 | 手不是机器 |
| 落点 | 精确 | 带 ±1~3px 抖动 | 真人不会每次都点同一个像素 |

## 为什么"可复现"和"像真人"不矛盾

看似矛盾：真人是随机的，怎么复现？

**答案**：随机性来自**种子化的熵源**。

```python
from avatar.human_entropy import entropy

entropy.seed(42)     # 固定种子
# 之后所有随机都从这个种子派生
```

- 对**外部观察者**：轨迹看起来是自然的、不可预测的
- 对**我们自己**：同一个种子跑两次结果完全一样

这是**可测试的真人化** —— 否则每次跑测试轨迹都不同，
根本没法写断言。

## 实测数据

```
机械移动 2880x1800 屏幕：
  平均耗时 12ms，落点误差 0px

真人化移动同一段距离：
  平均耗时 680ms，落点误差 ±1.4px
  速度峰值出现在 62% 行程处（真人典型值 55~70%）
  震颤主频 9.3Hz（真人典型 8~12Hz）
```

**这就是"像人"的量化定义** —— 不是"看起来像"，
是几个具体指标落在人类的区间里。
